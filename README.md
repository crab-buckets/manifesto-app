# Manifesto - Secretive Notice Board


A classified intelligence and case-file management system built around persistent records, clearance levels, and controlled information.



## Clearance System

Manifesto uses a three-level clearance system:

- Level 0 ───────────────── Everyone
- Level 1 ───────────────── Restricted
- Level 2 ───────────────── Warden


A user's clearance determines whether they can view the contents of restricted intelligence.

Users without sufficient clearance may still be able to see that a record exists, while its contents are obscured.

Wardens bypass normal clearance restrictions.
## Immutable History
Manifesto is designed around the idea that intelligence records should not silently disappear.

Reports, revisions, addenda, attachments, and other historical records use database-level protections to prevent accidental modification or deletion.

Instead of rewriting history:

Original Report

│

├── Revision

│

├── Revision

│

└── Addendum


Changes are recorded as new historical entries.

This provides an auditable record of how information changed over time.
## Automatic Tagging

Reports can be automatically associated with relevant tags based on their contents.

The system can identify mentions of:
 - Persons of interest
 - Factions
 - Faction members
 - Other configured categories

Creating a new tag can also backfill existing reports that contain matching information.

This allows the archive to become increasingly interconnected as new intelligence is entered.
